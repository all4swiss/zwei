# Zwei

Personal gym + home blood-pressure log for Lu. Data stays in the browser (`localStorage`). No accounts, no medical advice, no scoring of readings.

This repository is **already public** (GitHub Pages on `main` / root). Do not change visibility. Do not add extra public Pages sites. Do not commit real measurements.

## Use

iPhone: open the existing Pages site, then Safari → Share → Add to Home Screen. Or open `index.html` locally.

- **Training:** Einheit A. Check a set to start a 1-minute rest, or skip. Save the session or tap «Heute zählt». Goal: 2× per week.
- **Blood pressure:** systolic / diastolic, optional pulse. Banner if nothing logged today.

No family or reading values belong in git.
