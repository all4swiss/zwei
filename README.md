# Zwei

Einfaches Tracking für Lu: Einheit A (Gym) und Blutdruck zu Hause.

Keine Accounts, keine Bewertung der Messwerte, kein medizinischer Rat. Alles bleibt im Browser (localStorage).

## Auf dem iPhone

1. Repo: https://github.com/all4swiss/zwei
2. Datei `index.html` in Safari öffnen geht nur mit einem Host. Privat-Repo hat kein GitHub Pages.
3. Am einfachsten: auf dem Mac die Dateien lokal öffnen, oder das Repo öffentlich stellen und Pages auf `main` / root einschalten. Dann: Safari → Teilen → Zum Home-Bildschirm.

## Nutzung

- **Training:** Sätze abhaken (startet 1-Minute-Pause) oder Pause tippen. «Einheit speichern» oder nur «Heute zählt». Ziel: 2× pro Woche.
- **Blutdruck:** Systolisch / diastolisch, optional Puls. Banner wenn heute noch nichts eingetragen ist.
- Überzüge: Soll 10 Wdh (PDF stand 100). Ist zählt.
